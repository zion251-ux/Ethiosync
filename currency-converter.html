About this tool

Where do the exchange rates come from?

Rates are fetched live from the Frankfurter API — a free, open-source exchange rate service that aggregates reference rates from over 110 central banks and official sources. No API key is required and there are no usage quotas.

Are these live trading rates?

No. These are reference rates published once or a few times per day by central banks. They are ideal for accounting, billing, reporting and general conversions, but not for live trading or currencies with high intraday volatility.

How many currencies are supported?

The Frankfurter API covers 219 currencies and 39 other assets (including precious metals like gold and silver, plus major cryptocurrencies). Legacy currencies with historical data are also available.

Is my data sent anywhere?

Only the currency codes and amount you enter are sent to the Frankfurter API to fetch the rate. No personal data is collected, logged, or stored — the API does not record IP addresses or request URLs.
